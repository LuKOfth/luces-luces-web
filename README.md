# Luces, luces ✦ — V3
Videojuego pixel art de paseo que pasa progresivamente del atardecer al terror.

🎮 **Jugar:** https://lukofth.github.io/luces-luces-web/

Solo requiere un navegador: Android, iPhone o computadora. No hay que descargar ni instalar nada.

Este repositorio público contiene solamente la versión web de **Luces, luces V3**. No contiene el código ni los documentos privados de otros proyectos.

## Publicación
El archivo del juego es `index.html`. Hay un workflow en `.github/workflows/pages.yml` que publica GitHub Pages al actualizar `main`.

Para la primera publicación, ve a **Settings → Pages → Build and deployment → Source: GitHub Actions** y vuelve a ejecutar el workflow si es necesario.
